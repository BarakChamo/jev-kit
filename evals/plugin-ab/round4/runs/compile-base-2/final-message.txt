## Summary

Three files in the working directory:

- **`questions.json`** — an example Jev request: a realistic `state` (post + author + context) and a `questions` map covering the standard T&S categories (hate speech, harassment, violent threats, CSAE, sexual content, self-harm, spam/scam, regulated/illegal goods) as `noul` probability checks, plus one `score` question for overall severity and one `choice` question for a recommended action.

Thresholds are isolated as constants so they're tuned independently from the LLM-generated question content.
- **`generate-questions.prompt.md`** — the prompt that actually removes the policy team from the loop: fed the full policy doc, an LLM regenerates `questions.json` (one `noul` question per distinct rule, stable ids, section citations), with a note to diff against the prior version and require human sign-off only on id changes or CSAE/violence criteria changes before auto-deploying.
