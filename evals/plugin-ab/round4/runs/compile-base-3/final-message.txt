Created both files in the working directory:

- **`questions.json`** — an example Jev request: per-post `state` plus the `questions` map. The `_comment` field documents that this map is regenerated by an LLM pass over the policy PDF whenever policy changes, not hand-authored, and that `state.policy_version` ties a given question set back to the doc revision it came from. Covers the core policy categories with the three question types: `noul` for binary violations (violence, hate speech, spam/scam), `score` for graded severity (self-harm risk, sexual content), `choice` for categorical judgments (harassment target, and a holistic `recommended_action`).

- **`decide.ts`** — `decide(answers)` turns Jev's answers into `{action, escalateToHuman, reasons}`. It reads score-level ordering from `questions.json` at runtime (so it survives the policy doc, and the generated questions, changing shape) rather than hardcoding indices. Logic: self-harm at `ideation`+ always escalates to a human regardless of anything else; the `recommended_action` choice drives the default action but low-confidence answers escalate; and any hard-violation `noul` signal that disagrees with a lenient recommendation forces escalation instead of silently trusting either side.
