Summary of `adapter.ts`:
- `buildState(input)`: copies the 7 canonical fields (`repo`, `branch`, `runner`, `job_name`, `attempt_number`, `max_attempts`, `log_tail`) 1:1 into the state shape from `questions.json` (`log_lines` is unused since the state doesn't need it).
- `questions(input)`: returns `questions.json`'s single static `failure_cause` question verbatim (it's not built per-case).
- `decide(input, answers)`: repacks the API's choice answer (`{type, choice, confidence, probabilities}`) into the `{choice, confidence, probabilities}` shape `decideRetry` expects, calls `decideRetry` from `decide.ts`, and maps `retry`→`"yes"`, `no_retry`→`"no"`, `escalate`→`"abstain"`.
