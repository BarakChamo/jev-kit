Summary of `adapter.ts`:
- `buildState(input)` copies `repo`/`branch`/`runner`/`log_tail` and renames `attempt_number`→`attempt`, leaving `job_id`/`workflow` empty since the canonical input has no equivalent fields.
- `questions(input)` returns `questions.json`'s static `questions` map (no per-case construction needed here).
- `decide(input, answers)` strips the API's `type` tags off the `choice`/`noul` answers, calls `decide.ts`'s `decideRetry`, and maps its result to `{retry: "yes"|"no"|"abstain"}` (`retry: true` → yes, `escalate: true` → abstain, otherwise no).
